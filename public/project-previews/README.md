# Screenshots / original work only

For ClientFlow AI and AI Cyber Forensics, the website automatically searches the corresponding verified **public GitHub repository** for image files with descriptive screenshot, dashboard, evidence, Kanban, or UI-preview names. If GitHub is unavailable, it falls back to the original decorative project visual; this is intentionally **not** presented as an authentic screenshot.

For projects not publicly linked, please add genuine screenshots before representing them as real UI. Do not use invented interface renderings as screenshots of completed software.

To add a custom portrait: put `portrait.jpg` in the `public/` directory and edit `portrait: '/portrait.jpg'` in `src/data/profile.ts`. The default uses your GitHub avatar and falls back to the YS monogram if offline.
